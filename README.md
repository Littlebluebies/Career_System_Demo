# Demo · ระบบแนะนำอาชีพและวิเคราะห์ช่องว่างทักษะวิชาชีพ

เว็บสาธิตสำหรับสอบเค้าโครงโครงงาน คณะเทคโนโลยีสื่อสารมวลชน มทร.ธัญบุรี
ข้อมูลและผลแนะนำทั้งหมดเป็นข้อมูลจำลอง ยังไม่ใช่แบบจำลองที่สอนจากประกาศงานจริง

| ไฟล์ | หน้า |
| --- | --- |
| `index.html` | ฝั่งผู้ใช้งาน (นักศึกษา) |
| `researcher.html` | ฝั่งผู้วิจัย · บัญชีสาธิต `researcher` / `demo1234` |

ทั้งสองหน้ามีปุ่มสลับไปมาที่แถบด้านบน คำตอบที่ส่งจากฝั่งผู้ใช้จะไปแสดงในฝั่งผู้วิจัย
เมื่อเปิดในเบราว์เซอร์เดียวกัน (เก็บใน localStorage ของเบราว์เซอร์นั้นเท่านั้น)
ปุ่ม "รีเซ็ตข้อมูลจำลอง" ในฝั่งผู้วิจัยจะล้างคำตอบเหล่านี้

## Deploy ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ไว้ที่ root
2. ไปที่ Settings → Pages
3. Source เลือก Deploy from a branch, Branch เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
4. รอประมาณ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/`
